This project is the version of a web application that is made up of a frontend and a backend. The frontend is built using React. The backend is built using Node.js and Express. The project also uses a distributed database system that is set up using Docker.

The project is divided into three parts. The first part is the frontend folder that has the React application. The second part is the backend folder that has the Express server and the business logic. The third part is the database layer that is set up using Docker containers. These containers represent database sites or nodes. The backend talks to these databases using connections that are set up based on the distributed setup in the Docker environment.

The React application talks to the Express server using Axios or Fetch API. The project also uses CORS to allow requests, from different places.
